# Q4题意、时间线与结算口径

## 1. Q4是Q2/Q3的价格扩展

- Q4-2沿用Q2：每天0:00制定144段正常购电计划；日内只进行因果储能响应和紧急购电。
- Q4-3沿用Q3：0:00产生初始计划，6:00、12:00、18:00仅调整尚未执行的区间；过去动作和真实SOC冻结。
- 新增状态是随机实时电价。决策使用截至当前时刻的价格历史和因果价格预测，结算使用附件4当日真实交易时刻价格。

## 2. 防止价格泄漏

对回测日$d$，0:00价格模型只能用$r<d$的完整价格。Q4-3在时刻$h$只额外使用当日$[0,h)$已经实现的价格，对剩余预测作水平残差更新。附件4中$[h,24:00)$真实价格从不进入时刻$h$的优化。

## 3. 费用

正常购电、紧急购电分别按真实价格$p_{d,t}$和$5p_{d,t}$结算。Q4-3沿用Q3正文的逐次调整口径：调增净费用$1.5p_{d,t}u_{h,t}$，调减净费用$-0.5p_{d,t}v_{h,t}$。其中$q^{new}=q^{old}+u-v$，$u,v\ge0$。预测价格只出现在优化目标的条件期望或场景费用中，最终报告费用全部用真实价格重算。

## 4. 风险模型解释

目标$E[C]+\lambda\operatorname{CVaR}_\alpha(C)$中的$C$为场景内正常、调整和紧急购电总费用。CVaR采用Rockafellar–Uryasev线性化。正文是否采用CVaR由预先规定的判据决定：95%分位日电费至少改善2%，且平均费用增幅不超过2%。

## 5. 模型边界

附件4没有另给官方“日前电价预报”。因此本文从附件4历史中构造严格因果预测，而没有假定0:00能看到当天真实价格。Prophet、XGBoost、LightGBM的本机依赖不可用，相关失败与可复现替代法明确记录，不把替代结果冒充原包结果。
