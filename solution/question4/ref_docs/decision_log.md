# Q4决策日志

## 已采用

1. 价格预测主输入：HistGradientBoosting。其MAE最低（0.04318元/kWh），虽经济筛选中低偏置的persistence费用略低，但后者MAE为0.34988且95%分位日电费更高。选择统计—经济Pareto更稳定的梯度提升，年度费用差仅约0.14%。
2. Q4-2主模型：继承Q2的经验80%分位采购，价格换为因果动态预测。费用14720508.71元，低于首轮联合随机、DRO和CVaR方案，故没有为了复杂度放弃Q2结构。
3. Q4-3主模型：联合历史块场景的滚动随机MPC。费用14376895.52元，低于独立场景14504400.74元和确定性16894065.47元。
4. 场景降维：完整日/剩余时域误差向量联合聚类为5条代表路径，保留时序和跨变量依赖。

## 已实现但未作为主模型

- Q4-2：独立抽样、联合历史块、低秩多元高斯、Gaussian Copula、Vine式尾部耦合、条件状态场景、鲁棒、尾部加权DRO、9组CVaR。
- Q4-3：确定性动态价MPC、独立随机MPC、联合随机MPC、3个CVaR权重、PV/价格更新四组合消融。
- 风险模型：Q4-2的CVaR可降低平均费用，但相对候选基准没有把95%分位日电费改善到预设2%；Q4-3提高$\lambda$会显著减少紧急电量，但平均费用上升且95%分位改善不足，均放附录。
- Copula：Gaussian与Vine近似都完成经济回测，但有限样本下尾部依赖估计不稳定，费用高于历史块或低秩高斯。

## 失败或依赖受限

- XGBoost、LightGBM、Quantile LightGBM：本机缺少`libomp`导致导入失败；分别以HistGradientBoosting平方损失和分位损失作替代实验。
- Prophet：环境未安装，使用因果加性趋势+年度/周Fourier的Prophet-like基准。
- 标准GARCH包未安装，使用AR条件均值+EWMA条件方差的AR-GARCH式基准。
- 完整高维Vine Copula：365个日样本不足以稳定估计288维藤结构，采用日严重度的两层条件耦合近似，完整模型只保留为理论候选。

## 关键实验判断

- 独立抽样破坏相关结构：Q4-2独立场景15358695.49元，联合历史块15176021.69元；Q4-3独立14504400.74元，联合14376895.52元。
- Q4-2首轮随机模型仍不及原Q2策略重结算，因此补做经验分位0.70—0.95扫描；0.80分位最低，最终替换首轮候选。
- 价格日内更新的边际价值较小（约300元/年），原因是价格具有很强周周期且0:00预测已较准确；但动态价格建模相对固定价Q3策略在统一最终净额口径下节省约88095.32元。
