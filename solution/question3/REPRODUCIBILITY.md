# 问题 3：1370 万元结果复现说明

## 运行方式

在项目根目录执行：

```bash
/usr/local/bin/python3 -m pip install -r solution/question3/requirements.txt
/usr/local/bin/python3 solution/question3/main.py
```

经过验证的环境为 Python 3.12.6、NumPy 2.4.4、SciPy 1.17.1、
scikit-learn 1.9.0、pandas 3.0.3、openpyxl 3.1.5。

## 主结果

回测区间为 2025-02-01 至 2025-12-31，共 334 天。默认参数为 90 天历史
窗口、5 个加权 K-means 完整日场景、0/6/12/18 时滚动更新、线性降尺度、
逐次调整结算和跨日连续 SOC。

| 指标 | 数值 |
|---|---:|
| 计划购电费 | 12,706,276.64 元 |
| 调减冲减 | -239,798.21 元 |
| 调增费用 | 723,207.02 元 |
| 紧急购电费 | 517,182.92 元 |
| 全年总费用 | **13,706,868.38 元** |
| 紧急购电量 | 92,255.93 kWh |

## 为什么旧环境会有小幅漂移

Python 3.10 / SciPy 1.10 / scikit-learn 1.2 在相同公式下得到约
13,719,796.82 元。原因不是未来数据泄漏或结算公式变化，而是：

1. K-means 本身是非凸问题；即使固定随机种子，不同 sklearn 版本的初始化和
   数值路径仍可能落入不同局部最优簇；
2. 购电 LP 存在多重最优解；不同 HiGHS 版本可能返回期望目标相同、但逐时购电
   承诺不同的极点；
3. 这些微小决策差异经实际净负荷结算和跨日 SOC 传递后，会形成约 0.094% 的
   全年费用差异。

因此论文结果应同时给出算法参数和软件版本。`main.py` 会在版本不一致时提示，
不会静默声称精确复现。原两阶段实现仍可通过 `--engine legacy` 调用。
